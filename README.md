# Volkmar's Homebrew tap

```sh
brew install volkmar/tap/zerogpt-skill
zerogpt-skill install
zerogpt-check login
```

[ZeroGPT skill source and documentation](https://github.com/volkmar/zerogpt-skill)

The package includes an automatically selectable Codex skill and a command-line scanner. Default workflow: check prose, revise using ZeroGPT feedback, and rescan until AI score ≤10% or five scans have been used. Login uses the ZeroGPT Business account email/password flow and saves only its bearer token locally. Funded API access is required.
